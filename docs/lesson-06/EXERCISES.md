# 第 06 课练习

## 必做：许可异常安全

修复 `PermitGuardExercise`，保证：

- 成功 acquire 后一定 release。
- action 正常返回、受检异常、运行时异常时都成立。
- acquire 自身被中断时不能错误 release。

```bash
mvn -Dtest=PermitGuardExerciseTest test
```

## 选型题

分别选择同步器并解释：

1. 主线程等待 20 个服务完成初始化。
2. 每轮 5 个分片任务完成后统一合并，然后开始下一轮。
3. 外部供应商接口最多允许 30 个并发请求。
4. 任务阶段数量会动态增减。

## 死锁题

为两个账户转账设计固定锁顺序。说明：

- 如何生成稳定顺序。
- 两个账户顺序值相同时如何处理。
- 持锁期间哪些操作必须避免。
