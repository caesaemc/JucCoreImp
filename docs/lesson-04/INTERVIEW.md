# 第 04 课面试复盘

## 1. CAS 是什么？

比较当前位置是否仍为预期值，如果相等则原子替换，否则失败。失败方通常重新读取并重试。

## 2. CAS 一定比锁快吗？

不一定。低竞争、短操作时优势明显；高竞争会产生大量重试和缓存一致性流量，锁的阻塞或队列化可能更合适。

## 3. 什么是 ABA？

值从 A 变为其他值又回到 A，CAS 只看当前值会误认为未改变。中间历史重要时需要版本戳等方案。

## 4. AtomicLong 和 LongAdder 如何选？

强一致单值使用 AtomicLong；高竞争指标统计使用 LongAdder。LongAdder 的并发 sum 不是原子快照。

## 5. VarHandle 和 Unsafe 的关系？

VarHandle 是 Java 9 引入的公开、受支持变量访问 API，提供多种内存访问模式和原子操作；Unsafe 是内部实现工具，不应作为一般业务依赖。

## 6. CAS 的线性化点在哪里？

成功的原子比较替换动作。失败尝试没有改变共享状态。

## 场景题

高并发接口需要统计 QPS，同时定时上报：

- 指标不参与资金或业务决策。
- 写远多于读。
- 可接受上报时为近似快照。

优先考虑 LongAdder；定时读取 sum，并明确 reset 与并发更新的语义。
